# Design System — "Caderno físico" v2

Pack de design do Caderno de amigos. Consulte `spec.md` como fonte principal para implementação da UI em Vue.

Este diretório contém tokens CSS, protótipo HTML, prints de referência e guia de identidade visual.

O favicon do app fica em `frontend/public/favicon.svg` e reproduz `design/icon.svg`, preservando o símbolo e a paleta da marca.
